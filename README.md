
# Windows 11 Endpoint Management Deployment

**Project Type:** Real-World IT Deployment  
**Date:** June 2025  
**Environment:** 12 Windows 11 Systems

##  Project Overview

This project involved deploying and configuring Microsoft Entra ID (formerly Azure AD) and Microsoft Intune across 12 Windows 11 computers for a small educational organization.

The work focused on endpoint management, system policies, administrative permissions, and resolving software access issues across shared user profiles.

##  Technologies Used

- Microsoft Intune
- Windows PowerShell
- User Account Control (UAC)

##  Technical Challenges & Solutions

### Administrative Permissions and UAC

**Challenge:** Administrative permissions and User Account Control restrictions created problems with software access.

**Solution:** Used PowerShell-based automation and Windows troubleshooting to address administrative permission issues.

### Shared User Profile Software Access

**Challenge:** Software accessibility needed to be addressed across shared Windows user profiles.

**Solution:** Investigated permission-related issues and implemented adjustments to enable software access.
